# Coffee R Us 

## About the Project

Coffee R Us is a React-based coffee shop application that allows customers to explore coffee products and administrators to manage the coffee catalogue.

## Features

- Home page with navigation.
- Shop page displaying available coffee products.
- Dynamic search functionality.
- Filter coffee products by location.
- Admin portal for adding coffee products.
- Edit existing coffee product details.
- Delete coffee products.
- Data persistence using JSON Server.
- Client-side routing using React Router.
- Custom React hook for managing coffee data.
- Responsive design.

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- React Router DOM
- JSON Server
- Vitest
- React Testing Library

## Project Setup

Clone the repository:

```bash
git clone git@github.com:wandirihannah-cloud/coffee-r-us-assessment.git
```

Navigate into the project directory:

```bash
cd coffee-r-us-assessment
```

Install dependencies:

```bash
npm install
```

## Running the Application

Start the backend server:

```bash
npm run server
```

Open a second terminal and start the frontend:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Running Tests

```bash
npm test
```

## Building the Application

```bash
npm run build
```

## Backend API

The application uses JSON Server with `db.json` to manage coffee products.

API endpoint:

`http://localhost:3001/products`
